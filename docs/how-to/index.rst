=============
How-to guides
=============

Recipes for getting a specific job done. They assume you already have django-finder installed
and running — if you do not, start with :doc:`../tutorials/getting-started`.

Unlike the tutorials, these guides do not need to be read in order, and they do not explain
the reasoning behind what they tell you to do. For that, see :doc:`../explanation/index`.
